# DSGN — Design Agency Landing Page

DSGN is a responsive one-page website for a design studio/agency, featuring a projects showcase, studio section, news block, and contact details. The layout is built as a flexible (rubber) grid and optimized for Retina displays. :contentReference[oaicite:0]{index=0}
