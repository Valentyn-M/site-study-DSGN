# DSGN — Design Agency Landing Page

DSGN is a responsive one-page website for a design studio/agency, featuring a projects showcase, studio section, news block, and contact details. The layout is built as a flexible (“rubber”) grid and optimized for Retina displays.

## Live Demo
- https://valentyn-m.github.io/DSGN_Design-Agency/

## Key Features
- One-page layout with top navigation: Home, Projects, Studio, News, Contact
- Projects gallery with category filters (All / House / Commercial / Personal / Studio Lab)
- Detailed project cards (designer/assistant, materials, typology, client, year) + “View project” CTA
- Timeline navigation by year (e.g., 2014–2010)
- Studio section with team/staff profiles and imagery
- Flexible (“rubber”) layout + Retina-ready presentation
- Grid-based page structure and responsive styling

## Technologies Used
- HTML5
- CSS3 (grid-based layout, responsive styling)
- JavaScript (basic UI interactions)
